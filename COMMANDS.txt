------------------------------------------------------------------------------
 0. BEFORE ANYTHING ELSE
------------------------------------------------------------------------------

No login is needed. Every player on the server can use every command
below, straight after joining.

Join the server, open chat (press T), and type /cheats at any time for
the in-game command list.

WANT TO LOCK THEM DOWN AGAIN?
    Open filterscripts/cheats.pwn, find this line near the top:

        #define REQUIRE_ADMIN         0

    Change the 0 to a 1, then rebuild and restart:

        ./tools/build.sh filterscripts/cheats.pwn

    Now every command requires /rcon login root first, using the
    rcon_password from server.cfg.

    Worth doing if you ever open this server to the internet: as it
    stands, anyone who joins can spawn a tank, and /get lets them drag
    other players across the map.

NOTE: GTA's normal single-player cheat codes (HESOYAM, AEZAKMI, ...) do
NOT work in SA-MP and never will. SA-MP removes them on purpose. The
commands below are the replacement.


------------------------------------------------------------------------------
 1. HEALTH, ARMOUR, GOD MODE
------------------------------------------------------------------------------

/hp [amount]              Set your health. No number = 100 (full).

    /hp                   full health
    /hp 50                half health
    /hp 100               full health
    /hp 5000              way above max - you survive almost anything,
                          but the HP bar looks odd. Use /god instead.
    /hp 1                 nearly dead (handy for testing)

/armour [amount]          Set armour. No number = 100 (full).
/armor  [amount]          Same thing, American spelling also works.

    /armour               full armour
    /armour 100           full armour
    /armour 0             remove armour

/god                      Toggle god mode ON / OFF. Type it again to turn
                          it off. While ON, your health is topped up every
                          second, and the vehicle you are driving is held at
                          full health too (it can still look dented - use
                          /fix for the cosmetic damage).

    /god                  -> "God mode ON"
    /god                  -> "God mode OFF"

    God mode stays on until you type /god again, or until you leave
    the server.

    God mode does NOT protect against: drowning, falling out of the map,
    or being set on fire in some cases. It is health regen, not a shield.

/jetpack                  Instantly gives you a jetpack.

    Controls once you have it:
      W / S       = forward / back
      SPACE       = go up
      LEFT CTRL   = go down
      F or ENTER  = drop off the jetpack


------------------------------------------------------------------------------
 2. MONEY
------------------------------------------------------------------------------

/cash [amount]            ADDS money to what you already have.
                          No number = adds 100000.

    /cash                 +$100,000
    /cash 500             +$500
    /cash 1000000         +$1,000,000
    /cash -5000           TAKES $5,000 away (negative works)

/setcash (amount)         SETS your money to exactly this. Wipes what you
                          had first. Amount is required.

    /setcash 999999       you now have exactly $999,999
    /setcash 0            broke

    Difference in one line:
      /cash 100     ->  you had 500, now you have 600
      /setcash 100  ->  you had 500, now you have 100

    Max money in GTA SA is $999,999,999. Going over that displays wrong.

 5. TELEPORTING
------------------------------------------------------------------------------

/tp (x) (y) (z)           Teleport to exact coordinates. If you are driving,
                          the car comes with you.

    /tp 2495.0 -1687.0 13.5     Grove Street, Los Santos
    /tp 1685.0 -2333.0 13.5     Los Santos International Airport
    /tp 2027.0 1007.0 10.8      The Strip, Las Venturas
    /tp -1980.0 300.0 35.0      San Fierro, Doherty
    /tp -2340.0 -1600.0 483.0   Top of Mount Chiliad
    /tp 213.0 1920.0 17.0       Area 69 (the restricted military base)
    /tp 2495.0 -1687.0 500.0    Grove Street, but 500m up in the sky

    The third number is HEIGHT. If you end up stuck inside the ground,
    run the same command with a bigger z. If you teleport high up, grab
    a parachute first with /wep 46.

    Fun combo: /veh 411, then /tp 2495.0 -1687.0 800.0 and ride it down.

/goto (playerid)          Teleport yourself TO another player.
/get  (playerid)          Teleport another player TO you.

    /goto 0               jump to player ID 0
    /get 1                drag player ID 1 over to you

    Player IDs are shown in the scoreboard (hold TAB). They are small
    numbers starting at 0, not names. You are usually 0 if you're alone.

    afterwards if you lose them.

/weather (id)             Change the weather for the WHOLE server. 0-45.

    /weather 0            bright clear sky
    /weather 1            normal sunny
    /weather 5            San Fierro sunny
    /weather 8            RAIN and thunder
    /weather 9            thick fog
    /weather 11           blinding Las Venturas sun
    /weather 16           rainy countryside
    /weather 19           SANDSTORM (desert, orange haze)
    /weather 20           murky green "underwater" look

/time (hour)              Set the world clock, 0-23. Also server-wide.

    /time 0               midnight
    /time 6               sunrise
    /time 12              midday
    /time 20              sunset
    /time 23              night

    Note: /weather and /time affect every player on the server, not
    just you.

    The server starts locked to weather 11 and 12:00 - clear sky, midday
    sun, no clouds or fog, so you can fly and still see buildings from a
    distance. It stays there; the time of day never rolls into night on
    its own. /weather and /time change what it is locked to, so whatever
    you set is what everyone keeps until someone sets it again.

 8. IF SOMETHING DOESN'T WORK
------------------------------------------------------------------------------

"You are not logged in as an admin"
    Only appears if REQUIRE_ADMIN is set to 1 in cheats.pwn. Run
    /rcon login root. Logging in is per-session, so reconnecting or a
    server restart logs you out again.

"SERVER: Unknown command" / nothing happens
    The cheats filterscript isn't loaded. Check that server.cfg has
    "cheats" in the filterscripts line, and restart the server.

The car spawns but I'm not inside it
    Happens if you were already in another vehicle. Get out and retry.

"/veh : could not create vehicle (server limit reached)"
    SA-MP caps total vehicles at 2000, and grandlarc already loads 1781
    from its vehicle files, so you have roughly 219 spare slots.
    Restart the server to clear the ones you spawned.

My health keeps resetting / I can't die
    God mode is still on. Type /god to turn it off.

Everything is laggy and players teleport around
    Unrelated to cheats - check onfoot_rate in server.cfg. Normal is
    30-40. It is currently set very high, which delays sync updates.

I changed cheats.pwn and nothing changed in game
    You must recompile and restart:
        ./tools/build.sh filterscripts/cheats.pwn
        (then restart the server)
